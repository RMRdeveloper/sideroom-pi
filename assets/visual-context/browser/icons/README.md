# Browser icon

White `S` on opaque black, rendered with **Archivo Variable**, the text family
in Sideroom's `DESIGN.md` and `site/src/styles/site.css`. Weight: 700. Source:
`site/node_modules/@fontsource-variable/archivo/files/archivo-latin-wght-normal.woff2`.

The PNGs are 16, 32, 48 and 128 pixels. Each canvas uses `#000000`, a `#ffffff`
glyph at 86% of canvas size, and centers the glyph's actual ink bounds. These
are rendered font glyphs; the browser does not need the font installed.
