Add `sideroom_persona`: one built-in voice for every answer. A short reminder
rides the system prompt on each turn — so it survives compaction — and the
complete guide ships as the on-demand `sideroom-persona` skill. The voice is
direct and dry, free of filler, and plain enough to leave no doubt about what
is being discussed, while naming things as the user named them.

Decorative symbols in the lines a `write` or `edit` adds block the mutation, and
a prohibition that keeps firing degrades to a steer so the agent never
dead-locks. Flattering openers, hedging, automatic apologies, and AI
meta-commentary are answered with a steer capped per run. There are no profiles
and no persisted profile selection: `sideroom_persona` only reads the active
rules.
